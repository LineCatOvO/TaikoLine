## 失败测试详情

### 1. test/unit/game/test_scroll.gd (3个失败)

**失败原因**：BPM/滚动变化处理相关测试

**分析**：
- 测试用例 `test_scr_006_bpm_change_handling` 和 `test_scr_007_scroll_change_handling` 可能与实际的 BPM/滚动变化处理逻辑存在差异
- 可能是测试期望值与实际实现不一致

**影响级别**：低（核心功能正常，边缘情况处理可能需要调整）

### 2. test/integration/audio_sync/test_audio_sync.gd (5个失败)

**失败原因**：音频同步相关测试

**分析**：
- 音频同步测试在 headless 模式下可能受限
- 音频文件（test.ogg）可能不存在
- Mock AudioManager 的行为可能与实际实现有差异

**影响级别**：中（音频同步是游戏核心功能，但 headless 测试环境限制）

### 3. test/integration/game_flow/test_game_flow.gd (1个失败)

**失败原因**：魂槽数据完整性测试

**分析**：
- `test_gf007_soul_gauge_data_integrity` 测试可能期望特定的魂槽计算结果
- 魂槽清除阈值判断可能需要调整

**影响级别**：低（单个测试失败，不影响核心功能）

### 4. test/integration/game_flow/test_parse_to_play.gd (5个失败)

**失败原因**：解析到游玩流程测试

**分析**：
- 测试期望的解析结果与实际实现可能存在差异
- BPM变化时间点计算可能需要调整
- 音符时间计算与BPM关联测试可能需要修正

**影响级别**：中（解析到游玩流程是核心功能）
