# 任务文档：完善谱面编辑器高级功能

**任务ID**: task-P1-advanced-editor-features
**优先级**: P1
**状态**: 已完成

**完成时间**: 2026-04-05

---

## 任务目标

完善 TaikoLine 项目谱面编辑器的高级功能，包括：
1. 分支编辑（普通/玄人/达人分支切换和编辑）
2. 预览播放（实时预览谱面效果）
3. 撤销/重做（操作历史管理）
4. 节拍器（BPM 节拍提示）

---

## 现有功能分析

### 已实现的基础功能
- **编辑器框架**: editor.gd, editor_controller.gd 已完成
- **数据结构**: editor_data.gd 定义完整的音符、小节、分支数据
- **分支编辑器**: branch_editor.gd 已实现基本 UI 和功能
- **预览控制器**: preview_controller.gd 已实现播放控制
- **撤销/重做管理器**: undo_redo_manager.gd 已实现命令管理
- **节拍器**: metronome.gd 已实现基本节拍功能

### 需要完善的功能
1. **分支编辑**:
   - 分支切换时数据同步不完整
   - 分支条件编辑器需要与控制器完全集成
   - 分支小节数据管理需要完善

2. **预览播放**:
   - 播放时节拍器同步需要完善
   - 播放位置与时间线视图同步需要优化
   - 音频加载状态管理需要完善

3. **撤销/重做**:
   - undo_redo_manager.gd 已实现但未完全集成到 editor_controller.gd
   - 需要使用增强版管理器替代简单撤销栈
   - 命令合并和命令组功能需要启用

4. **节拍器**:
   - 节拍器与播放同步需要完善
   - 节拍器 UI 控制需要添加
   - 节拍器音效需要优化
