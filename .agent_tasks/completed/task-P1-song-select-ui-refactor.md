## 有价值发现

### 发现一：Godot 4.4 场景文件格式
**发现时间**：2026-04-03
**发现内容**：Godot 4.4 的场景文件使用 `uid://` 格式的资源引用，需要确保 UID 正确
**价值说明**：避免资源引用错误
**应用建议**：创建新场景时使用 `uid://` 格式引用资源

### 发现二：选歌界面背景颜色
**发现时间**：2026-04-03
**发现内容**：选歌界面使用蓝紫色系背景（Color(0.1, 0.08, 0.25, 1.0)）更符合太鼓达人风格
**价值说明**：提升视觉一致性
**应用建议**：其他界面可参考此颜色方案
