# TaikoLine 音效资源

本目录存放游戏所需的音效文件。

## 音效文件列表

| 文件名 | 描述 | 用途 |
|--------|------|------|
| `don.ogg` | 红音符打击音 | 玩家击打红音符（咚）时播放 |
| `ka.ogg` | 蓝音符打击音 | 玩家击打蓝音符（咔）时播放 |
| `balloon.ogg` | 气球打击音 | 气球音符连打时播放 |
| `judge_perfect.ogg` | 良判定音 | 获得良判定时播放 |
| `judge_good.ogg` | 可判定音 | 获得可判定时播放 |
| `judge_miss.ogg` | 不可判定音 | 获得不可判定时播放 |
| `combo_bonus.ogg` | 连击加成音 | 达到特定连击数时播放 |

## 音效格式要求

- **格式**: OGG Vorbis
- **采样率**: 44100 Hz（推荐）
- **声道**: 单声道（打击音效）/ 立体声（判定音效）
- **时长**: 
  - 打击音效：0.1-0.3秒
  - 判定音效：0.2-0.5秒

## 音效来源建议

1. **自制音效**: 使用音频编辑软件（如 Audacity）录制或合成
2. **免费音效库**: 
   - Freesound.org
   - OpenGameArt.org
   - Zapsplat.com

## 注意事项

- 确保音效文件大小适中（建议每个文件 < 100KB）
- 音效应有清晰的起音，避免过长的衰减
- 打击音效应具有冲击力，便于玩家获得即时反馈
- 判定音效应与打击音效有明显区别

## 占位文件

当前目录包含占位文件，实际音效文件需要另行添加。
音效加载时会自动检测文件是否存在，不存在时会在控制台输出警告但不影响游戏运行。
