# TaikoLine

**太鼓达人风格节奏游戏模拟器** - 使用 Godot 4.4 和 GDScript 开发

## 项目介绍

TaikoLine 是一个开源的太鼓达人风格节奏游戏模拟器，支持 TJA 格式谱面文件的解析和游玩。项目采用模块化设计，具有完整的游戏系统架构。

## 功能列表

### 核心功能

- **TJA 谱面解析** - 完整支持 TJA 格式谱面文件解析
- **音符系统** - 支持所有音符类型（红、蓝、大音符、连打、气球、久寿玉等）
- **判定系统** - 三级判定（良、可、不可）与精确判定窗口
- **分数系统** - 完整的计分机制，支持连击加成
- **魂槽系统** - 魂槽进度与清除判定

### 谱面特性

- **多难度支持** - Easy、Normal、Hard、Oni、Edit 等难度
- **BPM 变化** - 支持 #BPMCHANGE 命令
- **滚动速度** - 支持 #SCROLL 命令
- **拍号变化** - 支持 #MEASURE 命令
- **Go-Go Time** - 支持 #GOGOSTART/#GOGOEND 命令
- **分支谱面** - 支持 #BRANCHSTART/#BRANCHEND 分支系统

### 音频系统

- **背景音乐播放** - 支持 OGG 音频格式
- **音效系统** - 打击音效与判定音效
- **音频同步** - 可调节音频偏移

### UI 组件

- **分数显示** - 带动画的分数显示组件
- **连击显示** - 高亮连击数显示
- **魂槽显示** - 进度条与阈值指示
- **判定显示** - 判定结果反馈

## 使用说明

### 环境要求

- Godot 4.4 或更高版本

### 运行项目

1. 使用 Godot 编辑器打开项目
2. 打开 `scenes/main.tscn` 作为主场景
3. 按 F5 或点击运行按钮启动游戏

### 操作方式

| 按键   | 功能         |
| ------ | ------------ |
| F      | 红音符（左） |
| J      | 红音符（右） |
| D      | 蓝音符（左） |
| K      | 蓝音符（右） |
| Enter  | 确认         |
| Escape | 取消/返回    |

### 添加谱面

1. 在 `songs/` 目录下创建新文件夹
2. 放置 `.tja` 谱面文件和对应的音频文件
3. 确保 TJA 文件中的 `WAVE` 字段指向正确的音频文件
